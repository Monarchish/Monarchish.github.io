# 支援未来 · 操作手册站

个人上班用的 SOP 手册站。纯静态页面，没有构建步骤、没有后端，
GitHub 上改了文件、网站就跟着变。

> 一句话：**改内容 = 把 `.md` 丢进对应文件夹；改外观 = 去 `02、设置/`。**
> 平时都不需要碰 `index.html`。

---

```

│
├── 01、支援未来/            ← 文档正文（.md）。改内容只动这里
│   ├── 01.准入/
│   ├── 02.采购/
│   ├── 03.销售/
│   ├── 04.财务/
│   └── 05.其他/

└── 02、设置/                ← 主页的功能代码与样式
    ├── 01.站点主程序.js      ← 目录清单 + 正文渲染（改清单在这）
    ├── 02.站点样式.css       ← 站点主体的外观
    ├── 03.Hero门面样式.css   ← 滚动门面（首页大图那屏）
    ├── 04.Hero门面.js
```

写在最后，它的规则会盖住前面同名的。

## 二、怎么加一篇新工序

### 1. 找到放哪儿

打开 `01、支援未来/`，下面有五个分类：

```
01.准入    02.采购    03.销售    04.财务    05.其他
```

按你的工序属于哪一类，点进去。

### 2. 建一个流程文件夹

在分类目录里新建一个文件夹，名字按编号 + 工序名：

```
03.销售/03.11.保证金/
```

（编号接着当前最大的往下排就行，不用连号。）

### 3. 放一个索引文件

在这个新文件夹里放第一个文件，文件名必须是 **分类号.流程号.00.工序名.md**：

```
03.11.00.保证金.md
```

注意中间那个 **`.00.`**，它是这个流程的首页。同一流程的后续步骤文件用 01、02、03…：

```
03.11.00.保证金.md      ← 首页（必须）
03.11.01.登记.md
03.11.02.退款.md
```

**做完这三步就够了。** 网站下次打开会自动发现它，出现在首页目录和左侧菜单里
（最多 30 分钟缓存，一般刷新一次就出来了）。

## 三、常见问题

**Q：我加了但没出现？**
先确认三点：① 文件确实在 `01、支援未来/分类/流程/` 三层里面；② 首页文件名里有 `.00.`；
③ 后缀是 `.md` 小写。都对了还不出，就按 `Ctrl + F5` 强制刷新一次。

**Q：能删吗？**
能。直接删掉文件夹，网站下次打开就不再显示它（清单里残留的一条不会造成任何问题）。

**Q：想改首页五个章节的文案 / 配图？**
改 `02、设置/10.章节门厅.js` 最上面那张表（`HALL_IMG` 换图、`CROPS` 调裁剪位置、
章节文字也在同一处）。换图就把新图片放进 `02、设置/素材/`，再把 `HALL_IMG` 指过去。

**Q：想换门面（首页大图）的背景图？**
图片放 `02、设置/素材/`，然后改 `index.html` 里那行
`<img src="02、设置/素材/02.门面主图C.webp" ...>`。
注意门面里是**旋转 180°** 显示的（`03.Hero门面样式.css` 里的 `transform: scale(-1)`）。

**Q：想让目录页数、步骤数更准？**
那个数字来自首页文件里 `## FAQ` 之前的 `<!-- include: -->` 条数，拆子流程时会自动变。

**Q：为什么链接后面有 `?v=3` 这种数字？**
那是"缓存版本号"。改了某个 css/js 后，把这个数字加 1，访客的浏览器就知道要重新下载，
不会一直看到旧样式。

## 四、背后的原理（可跳过）

`02、设置/11.自动目录.js` 会在后台向 GitHub 要一次仓库文件清单（公开仓库，免登录，一次请求），
找出所有带 `.00.` 的索引文件，和你原来写死在 `01.站点主程序.js` 里的清单比对，
**只把新的补进去**。

它有三条安全边界：

- **只增不减**：清单里已有的条目一个都不动。
- **断网就装死**：GitHub 抽风、公司网络拦截时，它会一声不吭地放弃，
  站点照常用老清单工作，不会白屏、不会少内容。
- **结果缓存 30 分钟**：不会每次访问都去请求。

如果哪天你不想用它了，把 `index.html` 里 `<script src="02、设置/11.自动目录.js"></script>`
这一行删掉即可，一切回到原来的样子。

## 五、维护备忘

- **不要改** `index.html` 的文件名 —— GitHub Pages 只认 `index.html` 当首页。
- **不要删** `.nojekyll` —— 删了 GitHub 会拿 Jekyll 处理一遍仓库，中文目录名容易出问题。
- 站点顶部那行目录树注释（`index.html` 开头）跟着结构一起维护，改结构时顺手更新。
- 2026-10 做过一次仓库整理：删掉了不再使用的旧版动画包（原 `02、开屏动画/`，3.8 MB）
  和两张零引用的图片，备份在 `支援未来-仓库冗余备份-20261009.zip`。
  需要旧版开场动画的话，解压回去即可。
