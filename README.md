# 支援未来 · 门面站

纯静态单页：开场动画 → 滚动门面（双图渐变）→ 目录外壳。
没有构建步骤、没有后端，GitHub 上改了文件、网站就跟着变。

> 注意：正文文档（原 `01、支援未来/` 的全部 .md）已于 2026-10-27 按需移除，
> 站点只保留界面。git 历史里有完整备份，想恢复内容随时可以。

## 仓库结构

```
Monarchish.github.io/
├── index.html              ← 网站入口（GitHub Pages 的首页约定名，不能改）
├── README.md               ← 本说明
├── .nojekyll               ← 关掉 GitHub Pages 自带的 Jekyll 处理（别删）
│
└── 01、设置/                ← 功能代码与样式
    ├── 01.站点主程序.js      ← 目录外壳 + 正文渲染
    ├── 02.站点样式.css       ← 站点主体的外观
    ├── 03.Hero门面样式.css   ← 滚动门面（首页大图那屏）
    ├── 04.Hero门面.js        ← 门面滚动剧情 + 双图渐变
    ├── 05.内容门锁.js        ← 正文密码锁（内容恢复后自动生效）
    ├── 06.开屏动画样式.css   ← 进站的开场动画
    ├── 07.开屏动画.js
    ├── 11.自动目录.js        ← 扫描仓库自动建目录清单（文档移除后返回空，属正常）
    ├── 素材/                 ← 图片（门面主图 B/D、蒙版窗、方格网、开屏标志）
    └── 库/                   ← 自托管的第三方库与字体（不依赖外部 CDN）
```

**编号就是加载顺序**：`01`~`11` 从小到大依次生效。

## 常用调整

- **换门面主图**：替换 `01、设置/素材/06.门面主图B.webp`（结尾图）/ `07.门面主图D.webp`（开场图）。
- **改门面文案**：`index.html` 里搜 `hero-tut`，四个屏的标题正文都在那。
- **调双图渐变**：`01、设置/04.Hero门面.js` 搜 `swapProgress`。
- **调亮度**：同文件搜 `heroImgOverlayOpacity`。
- **开屏小字**：`01、设置/07.开屏动画.js` 顶部的 CONTENT 表。
