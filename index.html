FAQ · 这轮怎么理解

功能细节以后还能补；下面先把上线和用法说清楚。

这网站到底解决什么？

把上班工序做成「个人攻略本」：不会了就翻、就搜。不是公司级 SOP 系统，也不做多人协同。

为什么用 GitHub Pages，不用服务器？

纯静态页面，GitHub Pages 免费、稳定，绑定你的 username.github.io 就能多端打开。今天下午会议会直接帮你部署上去。

和现在的 WPS 在线文档比呢？
  • 保留你习惯的「目录」——左侧 TOC
  • 补强检索——顶部关键词搜索
  • 加上滚动介绍动效，查阅更像产品而不像表格
滚动感觉奇怪怎么办？

旧版常见问题是「内容和 scroll 没绑在一起」。这一版按内容块数量计算滚动距离，文案位移和进度条同步。可点「跳过动画」直接进手册。

以后要会议投屏 / 多人一起改呢？

那是工作流（账号、权限、协作），投入会上去。这轮先不做；开会时打开链接投屏就够用。真要上协作再说。

内容怎么更新？

你继续维护文档 → 导出/给我一份 → 更新 data/manual.json → 推到 GitHub，Pages 自动刷新。远程也可以手把手教。
