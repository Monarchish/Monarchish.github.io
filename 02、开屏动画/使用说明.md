## 二、命名规则（以后加东西照着来）

| 位置 | 规则 | 例子 |
|---|---|---|
| 一级文件夹 | **两位数字 + 顿号 + 中文名** | `01、支援未来`、`04、XX` |
| 文件夹内的技术文件 | **序号 + 中文名 + 原扩展名** | `1.动画播放器.js`、`2.站点样式.css` |
| 网页入口 | 固定叫 `index.html`（浏览器约定，访问目录时自动打开） | 根目录、02 各一个 |
| 文档正文 | 沿用原编号 | `03.09.00.销售开票.md` |

> **为什么数字要两位？** 一位数会在有第 10 个文件夹时排错：「10、」会跑到「2、」前面。
> 两位（01、02……10、11）永远按顺序排，加到 99 都不乱。

## 四、02、开屏动画 里每个文件干什么

| 文件 | 是什么 | 谁在用 | 要不要动 |
|---|---|---|---|
| `index.html` | 动画页入口。只负责搭舞台，然后加载播放器 | 被 6.主页挂载.js 以 iframe 加载 | 基本不用动 |
| `1.动画播放器.js` | **动画的大脑**。读动画数据 → 按帧求值 → 写 DOM 图层；播到收场点通知主页 | 被 index.html 加载 | 不用动 |
| `2.曲线求值.js` | **数学工具**。把关键帧用 Hermite 插值算成任意时刻的值 | 被 1.动画播放器.js 引用 | 永远不用动 |
| `3.动画数据.js` | **动画数据**。从游戏资源解包导出的图层树 + 全部曲线（390 帧 / 60fps / 总长 6.5s） | 被 1.动画播放器.js 动态加载 | **不要手改** |
| `4.行为配置.js` | **行为配置**。停在第几秒、藏不藏活动主界面、素材 CDN 地址 | 被 1.动画播放器.js 引用 | ★ 改动画就改它 |
| `5.动画页样式.css` | 动画页的样式：1920×1080 画布等比缩放（手机竖屏自动转 9:16） | 被 02 的 index.html 引入 | 一般不动 |
| `6.主页挂载.js` | **主页侧的挂载脚本**：建 iframe、监听消息、淡出覆盖层、超时兜底 | 被根目录 index.html 引入 | 一般不动 |
| `7.主页覆盖层样式.css` | 覆盖层的样式（盖住主页、淡出动画、锁滚动） | 被根目录 index.html 引入 | 一般不动 |
| `素材/贴图/` | 38 张 png，动画的画面素材 | 由 3.动画数据.js 里的路径引用 | 同名替换即可 |

## 五点五、聚合页怎么运作（2026-09-23 起）

像 `03.02.00.插行` 这类聚合页，骨架是「`## 工序名` + `<!-- include: xx.md -->`」。
1.站点主程序.js 会把它**按 `##` 标题切成多个「工序视图」**（include 在展开前切，子文档自己的 `##` 不受影响）：
- 右侧「本页指引」**只列工序名**（准发下载 / 整理表格 / 台账编辑），不再列出每个工序内部的 1、2、3 小节；
- **同一时间只显示一个工序**，默认第一篇；点右栏工序名切换，看完不会滚出下一篇；
- 没有 include 的普通页不切块，整页显示 + 原有 h2/h3 目录。
- 新增一篇 SOP = 在聚合页里加一段「`## 名称` + `<!-- include: 文件.md -->`」，右栏自动多一项。
- 加载性能：include 并行拉取 + 整页会话缓存 + 卡片/菜单悬停预取。
- **动作行一律一行一个动作**（超长会自动折行兜底），不要再写成一长串，否则会出现横向拉条。

## 五点六、首页为什么能秒开、要点表为什么有颜色（2026-09-23 起）

- **首页秒开**：门户和左侧菜单先直接用 `sidebarManifest` 清单画出来（标题取自文件编号，不联网、不等 anyone）；
  29 篇的标题/步骤数索引在后台并行抓，到位后原地精修文字。索引结果存 **localStorage（键 `support-future-index-v2`，12 小时有效）**，
  新开标签页/重开浏览器都不用重抓。改了文档内容想让卡片步骤数立刻刷新：控制台执行
  `localStorage.removeItem('support-future-index-v2')` 后刷新即可。
- **要点表配色**：要点表首列写 `⛔ 禁止 / ⚠ 注意 / ✓ 检验`，站点渲染时自动转成彩色 emoji
  （⚠️、✅）并给整行上底色、级别格上字色（红 / 琥珀 / 绿，与试点预览稿一致）。md 里**继续写 ⚠ 和 ✓ 原样字符**即可，不用自己加样式。

## 五点七、首页的门面长前言（2026-09-24 起，inversa 结构复刻版）

进站不再先播开屏动画，而是：**先是一层 LOADING 开屏（自制，节奏照 inversa），
涨满后淡出，落到 4 屏「门面」长前言上**（结构照 inversa.com 的 hero 复刻：
400vh 长滚动 + sticky 视口 + 像素菱形 mask 窗口随滚动 135%→64%→135% +
中段压黑去饱和 + 热点脉冲 + 双层地形交叉；配色/字体/代码/文案全部自有，
mask 图形为程序自生成，字体用免费的 Space Grotesk + JetBrains Mono）。

**LOADING 开屏**（`3.Hero门面样式.css` 的「七点五」段 + JS `bootSequence`）：
黑底全屏细点阵 + **屏幕中部一条横线**：左端 `LOADING...` 逐字打字框、
右端 `PHASE` / `FREQ 16HZ` 读数；横线上方**中间画幅从下往上生长**
（和门面地图同一个像素菱形 mask），**PHASE 就是画幅的生长指数**——
两者由同一个补间驱动，节奏开始快、收尾缓慢（power2.out）。
画幅涨满（首访约 2.2 秒）后**向全页扩充**再整层淡出、解锁滚动、
门面第 1 屏左下「支援未来」由下而上登场。
开屏的这段时间正是"加载器"窗口：文档索引 + 首页目录在后台备好
（`window.prefetchIndex`，`HeroFacade.start` 第一毫秒就催）。
加载期间锁滚动（`html.hero-booting body`）；回访快闪约 0.85 秒；系统
"减少动态效果"时直接跳过开屏。

| 屏 | 内容 |
|---|---|
| 1 | 大字「支援未来」逐字顶上 + kicker + meta + 切角按钮「Menu」（钉左下，点击直达目录） |
| 2 | 右侧注解：初衷 · 为什么要有这本手册（文案占位，标题滚动到跟前有乱码解码动画） |
| 3 | 左侧注解：小技巧 · 先看要点再动手（文案占位） |
| 4 | 右侧注解：小技巧 · 遇到异常不用慌（文案占位） |

- 滚动剧情（GSAP scrub，进度 0→1 对应刻度 0→10）：0-5 背景地图**向下**沉
  （前景文字随文档流向上滚出——反向视差，同参考站）；3-6 mask 收缩到 64% +
  压黑到 0.75 + 去饱和；5-6.2 「作业区」「操作要点」两个脉冲标签浮现、6.8 退场；
  7-10 mask 放大回 135%、地图回正、A 层（珊瑚红·现状）交叉到 B 层（薄荷·改善）。
- 右侧细进度线随滚动填满；桌面端有自定义光标（圆环 + 荧光进度圈 + 「滚动」标签，
  进度圈与滚动同步；触屏/窄屏不启用）。
- **滚轮是浏览器原生 1:1 手感**——平滑滚动库（Lenis）已按用户要求移除，勿加回。
- 注解文案集中在 `03、设置/4.Hero门面.js` 顶部 `CONTENT.notes`（标了【占位】的等定稿后替换）。
- 首次访问完整入场；回访（localStorage 键 `support-future-hero-seen-v1`）开屏快闪 + 短入场。
- 想直接进目录：`?jump=1`；想关掉门面回到旧版直开：`?hero=0`；想重看完整入场：`?seen=0`。
- 像素菱形 mask 收拢在 `3.Hero门面样式.css` 的 `--hero-mask` 变量里，开屏画幅与门面地图共用。
- 站点外壳顶栏的「支援未来」logo（`.top-nav .logo`）**已永久隐藏**（`2.站点样式.css` 末段）——
  全站只保留门面顶栏那一个；要恢复就删掉那段 `visibility: hidden`。

## 六、4.行为配置.js 配置项

| 配置项 | 当前值 | 作用 |
|---|---|---|
| `redirectUrl` | `"../index.html"` | 只在**单独打开** `/02、开屏动画/index.html` 时生效（跳回主页）。挂在主页里播时用不到 |
| `redirectAtSeconds` | `3.79` | 播到第几秒收场。3.75 是「眼睛」最清晰的一帧，3.79 是最黑的一帧；最大 6.5（完整剪辑） |
| `fadeOutMs` | `500` | 独立打开时的黑场淡出时长。挂在主页时由 6.主页挂载.js 负责淡出，此项不生效 |
| `hideFrontUi` | `true` | 隐藏剪辑自带的活动菜单 / 顶栏 / 仿游戏 HUD。**保持 true**，否则结尾会闪出游戏菜单 |
| `assetCdnBase` | jsDelivr 地址 | 素材 CDN 加速（国内访问 github.io 直连很慢）。填 `""` 可关闭；改动素材后 CDN 最长 12 小时才更新 |
| `enableDebugQuery` | `true` | 允许用网址参数临时覆盖上面的配置 |

**6.主页挂载.js 顶部也有一个 CONFIG**：`oncePerSession`（是否每次会话只播一次）、
`fadeOutMs`（覆盖层淡出 600ms，要和 7.主页覆盖层样式.css 里的 transition 一致）、
`loadTimeoutMs` / `playTimeoutMs`（卡住时的兜底收场时间，防止主页被卡死）。

## 九、旧链接怎么办

文件夹改名后，旧地址（例如 `/三、开屏动画/`）会 404，这是正常现象：
站点内部所有引用都已同步改成新名字，只有**外部收藏的旧链接**会失效。
如果哪天希望旧地址也能用，可以在仓库里加一个跳转页，随时说一声。
