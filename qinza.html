勤杂组 · OTL操作手册编写规范 · 纲要

==============================================================

一、核心哲学

本手册是一套面向未来自己的、可无脑执行的操作系统。其目标不是“记录知识”，而是将经验编译为精确的、不可再分的指令序列。所有规则皆为此服务：消除歧义，降低认知负荷，确保无论时隔多久、状态多差，都能按步骤完成操作。

二、架构体系

1. 组织层级

采用“司-局”二级架构，命名均为二字词，结构为“动词+动词”或“动词+名词”。

• 司：业务大模块。如“准入端”、“采购端”、“销售端”、“善后端”、“勤杂组”。

• 局：司下的子模块。如“准入”、“MDG”、“订货”、“销售合同”。

• 层级分隔符：·（空格+中点+空格）。示例：准入端 · 准入 · 邮件审批

2. 命名原则

• 职能明确：名称直接反映该模块的核心工作。

• 现代专业：风格参考现代职能机构（如香港警队部门命名），简洁有力，不刻意古典。

• 无重复字：所有“司”名中，核心动词互不重复，确保名称独立、不混淆。

三、格式与排版规范

1. 模块分隔

用等号构成的线条分隔主模块。

2. 标题层级

模块标题直接写在分隔线之间，层级清晰。

示例：准入端 · 准入 · 邮件审批

四、指令代码规范

1. 操作指令词

所有操作指令使用英文，并必须加粗、加上代码块底色。

常用指令词：Open、Write、Left Click、Right Click、Double Click、Ctrl + C、Ctrl + V、Ctrl + D、Ctrl + F、Ctrl + S、Ctrl + Alt + A、Filter、Enter、Esc

2. 操作对象

操作对象（如软件名、字段名、按钮名）使用双引号包裹。

示例：Open “W365 - 邮箱 - 写邮件”

3. 操作值与变量

• 变量：需要根据实际情况填入的内容，用方括号包裹。如：【客户名称】

• 固定选项：用 Or 连接，且 Or 需加粗、加代码块底色。

• 保留字：系统内约定俗成的短代码，直接书写。

4. 层级连接

当操作对象有层级关系时，用 -（空格+短横+空格）连接。

5. 分隔与停顿

• 软件窗口切换：用 ---（三个短横）分隔。

• 等待：暂未设置专门指令词，但在逻辑上隐含。

五、逻辑控制与注释

1. 分支与条件判断

使用 ⚠ 符号开头，表示一个重要的检查点或决策点。

• 检查点：⚠ 注意看“R - U”是否为“TRUE”。如果不是则需要检查原因。

• 决策点：⚠ 如果仓库回复在库，告知客户。⚠ 如果仓库回复不在库，继续下一步。

2. 注意事项

非操作指令的提示、说明、背景知识，直接书写，不加任何特殊符号。

==============================================================

勤杂组 · 宏程序 · 手工提单

==============================================================

过程名称：GenerateDeliveryOrder

功能描述：基于“———转货权———”工作表的筛选结果，动态生成标准化委托书，自动维护流水编号（存储于 N1 / O1），自动填充表尾日期与有效期，并将最终表格复制至剪贴板。

依赖工作表：———转货权———（数据源）、委托书（输出模板）

输出格式：A1:H(尾行) → 剪贴板

版本：v2.2 (消除G列空白行公式角标)

Sub GenerateDeliveryOrder()
    Dim wb As Workbook
    Dim wsSource As Worksheet, wsTarget As Worksheet
    Dim wsPrevious As Worksheet

    Set wb = ActiveWorkbook
    Set wsPrevious = ActiveSheet

    On Error Resume Next
    Set wsSource = wb.Sheets("———转货权———")
    If wsSource Is Nothing Then
        MsgBox "未找到数据源工作表：“———转货权———”，操作终止。", vbCritical
        Exit Sub
    End If

    Set wsTarget = wb.Sheets("委托书")
    If wsTarget Is Nothing Then
        Set wsTarget = wb.Sheets.Add(After:=wb.Sheets(wb.Sheets.Count))
        wsTarget.Name = "委托书"
        MsgBox "“委托书”工作表不存在，已自动创建。请预先设置好表头与表尾格式。", vbInformation
        Exit Sub
    End If
    On Error GoTo 0

    wsTarget.Activate

    Dim rngCounter As Range, rngDateMark As Range
    Set rngCounter = wsSource.Range("N1")
    Set rngDateMark = wsSource.Range("O1")

    If rngDateMark.Value <> Date Then
        rngCounter.Value = 1
        rngDateMark.Value = Date
    Else
        If IsNumeric(rngCounter.Value) Then
            rngCounter.Value = rngCounter.Value + 1
        Else
            rngCounter.Value = 1
            rngDateMark.Value = Date
        End If
    End If

    Dim lSeq As Long: lSeq = rngCounter.Value
    Dim sDocNo As String
    sDocNo = "ZJTCPJ-FC-" & Format(Date, "yyyymmdd") & "-" & lSeq
    wsTarget.Range("H2").Value = sDocNo

    Dim lLastRow As Long
    lLastRow = wsSource.Cells(wsSource.Rows.Count, "A").End(xlUp).Row
    If lLastRow < 2 Then
        MsgBox "数据源（———转货权———）无有效数据行。", vbExclamation
        wsPrevious.Activate
        Exit Sub
    End If

    Dim arrVisibleRows() As Long
    Dim lVisibleCount As Long, i As Long
    lVisibleCount = 0

    For i = 2 To lLastRow
        If wsSource.Rows(i).Hidden = False Then
            lVisibleCount = lVisibleCount + 1
            ReDim Preserve arrVisibleRows(1 To lVisibleCount)
            arrVisibleRows(lVisibleCount) = i
        End If
    Next i

    If lVisibleCount = 0 Then
        MsgBox "当前筛选条件下无可见数据，请检查 L 列筛选条件。", vbExclamation
        wsPrevious.Activate
        Exit Sub
    End If

    Dim lTargetRows As Long
    lTargetRows = IIf(lVisibleCount < 10, 10, lVisibleCount)

    Application.ScreenUpdating = False
    Application.Calculation = xlCalculationManual

    Dim lTailStartRow As Long
    Dim rngFound As Range
    Set rngFound = wsTarget.Columns(1).Find(What:="合计", LookAt:=xlPart)
    If rngFound Is Nothing Then
        MsgBox "“委托书”工作表 A 列未找到“合计”标识，表尾定位失败。", vbCritical
        Application.ScreenUpdating = True
        wsPrevious.Activate
        Exit Sub
    End If
    lTailStartRow = rngFound.Row

    If lTailStartRow > 8 Then
        wsTarget.Rows(8 & ":" & lTailStartRow - 1).Delete Shift:=xlUp
    End If

    If lTargetRows > 0 Then
        wsTarget.Rows(8).Resize(lTargetRows).Insert Shift:=xlDown
    End If
    lTailStartRow = 8 + lTargetRows

    Dim vCategory As Variant
    Dim rngCell As Range
    For Each rngCell In wsSource.Range("L2:L" & lLastRow).SpecialCells(xlCellTypeVisible)
        vCategory = rngCell.Value
        Exit For
    Next rngCell
    wsTarget.Cells(3, 2).Value = vCategory

    Dim lWriteRow As Long, j As Long, lSourceRow As Long
    lWriteRow = 8

    For j = 1 To lVisibleCount
        lSourceRow = arrVisibleRows(j)
        wsTarget.Cells(lWriteRow, 1).Value = wsSource.Cells(lSourceRow, 1).Value
        wsTarget.Cells(lWriteRow, 2).Value = wsSource.Cells(lSourceRow, 8).Value
        wsTarget.Cells(lWriteRow, 3).Value = wsSource.Cells(lSourceRow, 9).Value
        wsTarget.Cells(lWriteRow, 4).Value = wsSource.Cells(lSourceRow, 10).Value
        wsTarget.Cells(lWriteRow, 5).Value = wsSource.Cells(lSourceRow, 11).Value
        wsTarget.Cells(lWriteRow, 8).Value = wsSource.Cells(lSourceRow, 2).Value
        lWriteRow = lWriteRow + 1
    Next j

    Dim lFormulaRow As Long
    For lFormulaRow = 8 To 8 + lVisibleCount - 1
        wsTarget.Cells(lFormulaRow, 7).Formula = "=IF(A" & lFormulaRow & "<>"""",1,"""")"
    Next lFormulaRow

    wsTarget.Cells(lTailStartRow, 8).Formula = "=SUM(H8:H" & lTailStartRow - 1 & ")"

    wsTarget.Cells(lTailStartRow + 8, 8).Value = Date
    wsTarget.Cells(lTailStartRow + 4, 6).Value = Date + 5

    Dim arrRowHeights As Variant
    arrRowHeights = Array(16, 12, 18, 18, 32, 18, 32, 113, 15)
    Dim k As Integer
    For k = 0 To 8
        wsTarget.Rows(lTailStartRow + k).RowHeight = arrRowHeights(k)
    Next k

    If lTargetRows > 1 Then
        wsTarget.Rows(8).Copy
        wsTarget.Rows(9 & ":" & lTailStartRow - 1).PasteSpecial Paste:=xlPasteFormats
        Application.CutCopyMode = False
    End If

    With wsTarget.Range("A8:H" & lTailStartRow - 1)
        .Borders.LineStyle = xlContinuous
        .Borders.Weight = xlThin
    End With

    Application.Calculation = xlCalculationAutomatic
    Application.ScreenUpdating = True

    Dim rngCopy As Range
    Set rngCopy = wsTarget.Range("A1:H" & lTailStartRow + 8)
    rngCopy.Copy

    MsgBox "委托书生成完成。" & vbCrLf & _
           "数据行数：" & lVisibleCount & vbCrLf & _
           "中间区域行数：" & lTargetRows & vbCrLf & _
           "表尾起始行：" & lTailStartRow & vbCrLf & _
           "委托书编号：" & sDocNo & vbCrLf & vbCrLf & _
           "表格已复制至剪贴板，可使用 Ctrl+V 粘贴至目标位置。", vbInformation

    wsPrevious.Activate

End Sub
