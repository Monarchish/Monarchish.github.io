# 开屏动画 · 使用说明

> 「月行水上」（明日方舟 × 女神异闻录）风格的开屏动画，已接入支援未来主页。
> 访客打开 `monarchish.github.io` → 先播约 5 秒动画 → 淡出 → 直接进入"支援未来"主页。
> 动画本体来自开源项目 [Nyaasu66/ark-act54-web](https://github.com/Nyaasu66/ark-act54-web)（Unity 解包数据还原），仅供个人学习装饰使用，素材版权归原作者所有。

---

## 一、整体原理（它是怎么"长"在主页上的）

```
访客打开 index.html（支援未来主页）
        │
        ├─ <head> 里的一小段脚本：判断这次要不要播动画
        │     ├─ 本次会话已播过、或网址带 ?intro=0 → 不播，正常进主页
        │     └─ 要播 → 给 <html> 加 intro-on 类 → 黑色覆盖层立即盖住页面
        │
        ├─ overlay.js：往覆盖层里塞一个全屏 iframe
        │     └─ iframe 加载 三、开屏动画/index.html?embed=1，动画开始播放
        │
        ├─ （动画播放期间，主页的侧边栏和正文在覆盖层底下并行加载，
        │    所以动画一结束，主页是"已经就绪"的状态，秒开）
        │
        └─ 动画播到 4.8 秒 → 动画页给主页发一条消息 {type:"done"}
              → overlay.js 把覆盖层淡出（0.6s）并从 DOM 里删掉
              → 主页完全可交互
```

整个功能**只新增了一个文件夹 `三、开屏动画/`，外加 index.html 里的几行**。
想彻底移除：删掉 `三、开屏动画/` 文件夹 + index.html 里的 4 处标记（都带 `开屏动画` 字样注释）即可，主页原样恢复。

## 二、动画时间轴（每个"动作"的含义）

整段动画是一个 6.5 秒的 Unity 剪辑，被还原成 436 条动画曲线逐帧播放：

| 时间 | 画面 | 含义 |
|---|---|---|
| 0.0 – 0.5s | 黑场 + 小圆点脉冲 | 加载感，模仿游戏进入活动的黑屏 |
| 0.5 – 1.5s | "Changing Track..." + 墨滴 + 青色衬线标题浮现 | *Sur le lac lune vivante*（月亮行于水上）点题 |
| 1.5 – 2.9s | 巨型字母风暴 + 黑色液体飞溅 | P3R 标志性的视觉轰炸，情绪推到最高 |
| 2.9 – 3.8s | 深蓝字母墙 + 三个人物剪影 + 圆环 | 结城理一行人登场，收束情绪 |
| 3.8 – 4.5s | 主视觉展开 +「月行水上」标题定格 | 活动海报画面（原剪辑里随后的活动菜单按钮已被隐藏） |
| **4.8s** | **收场** | 冻结在标题帧 → 通知主页 → 覆盖层淡出 0.6s → 进入主页 |

> 收场时间点由 `intro-config.js` 里的 `redirectAtSeconds` 控制，最大可调到 6.5 看完整剪辑。

## 三、文件清单（每个文件是干什么的）

```
Monarchish.github.io/
├─ index.html                  ← 主页（改了 4 处，都有「开屏动画」注释标记）
├─ _headers                    ← 改了一行：X-Frame-Options DENY → SAMEORIGIN
│                                 （GitHub Pages 不理这个文件；是给以后换
│                                  Cloudflare Pages/Netlify 部署时兜底的，
│                                  不改的话 iframe 嵌自己会被安全头挡住）
└─ 三、开屏动画/                ← ★ 动画的全部东西都在这里
   ├─ index.html               动画页入口（被 iframe 加载的那个页面）
   ├─ app.js                   动画"播放器"：解析场景数据 → 逐帧求值动画曲线
   │                           → 合成图层；也负责收场（通知主页 / 跳转）和跳过按钮
   ├─ scene-data.js            动画数据：从 Unity AssetBundle 解包导出的
   │                           场景树 + 436 条动画曲线（JSON，约 350KB），别手改
   ├─ curve-runtime.js         曲线求值器：用 Hermite 插值把曲线算成每帧的
   │                           位移/旋转/缩放/透明度
   ├─ audio-timeline.js        音频调度：BGM 和音效跟动画时间轴对齐播放
   ├─ styles.css               动画样式：1920×1080 逻辑画布的缩放、图层、
   │                           跳过按钮、控制条；手机竖屏会自动旋转成 9:16
   ├─ intro-config.js          ★ 你唯一需要改的文件：所有行为配置都在这
   ├─ overlay.js               主页侧挂载脚本：建 iframe、收消息、淡出覆盖层
   ├─ overlay.css              覆盖层样式（盖住主页、淡出动画、锁滚动）
   ├─ 使用说明.md               本文件
   └─ assets/
      ├─ images/               92 张贴图（约 4MB，动画的画面素材）
      └─ audio/                2 个音频（BGM + UI 音效，约 215KB）
```

## 四、intro-config.js 配置项详解

| 配置项 | 默认值 | 作用 |
|---|---|---|
| `redirectUrl` | `"../index.html"` | **只在单独打开** `/三、开屏动画/` 时生效（跳回主页）。挂在主页里播时用不到 |
| `redirectAtSeconds` | `4.8` | 播到第几秒收场。想看完整动画调大，最大 6.5 |
| `fadeOutMs` | `500` | 独立打开时的黑场淡出时长。挂在主页时由 overlay.js 负责淡出，此项不生效 |
| `hideFrontUi` | `true` | 隐藏剪辑自带的活动菜单/顶栏/仿游戏 HUD。**保持 true**，否则结尾会闪出游戏菜单 |
| `allowSkip` | `true` | 右下角「跳过 ▶」按钮；空格 / 回车 / Esc 同效 |
| `unmuteOnFirstInteraction` | `true` | 访客第一次点击/按键时自动开启 BGM（浏览器要求必须先有交互） |
| `showControls` | `false` | 播放控制条。整站开屏保持 false，调试用 `?debug=1` |
| `enableDebugQuery` | `true` | 允许用网址参数临时覆盖以上行为 |

主页侧的行为在 **`overlay.js` 顶部的 CONFIG** 里：

| 配置项 | 默认值 | 作用 |
|---|---|---|
| `oncePerSession` | `true` | 每次会话只播一次（刷新不重播，重开标签页会播）。改成 `false` = 每次进站都播 |
| `fadeOutMs` | `600` | 覆盖层淡出时长（要和 overlay.css 里的 transition 一致） |
| `loadTimeoutMs` / `playTimeoutMs` | `20000` | 兜底：动画加载失败或卡住时，最多等 20 秒强制放行进主页，**永远不会把访客卡在黑屏** |

**网址调试参数**（加在主页地址后面）：

| 参数 | 效果 |
|---|---|
| `?intro=0` | 这次不播动画，直接看主页 |
| `?intro=1` | 强制重播（忽略"本会话已播过"） |
| `?debug=1` | 控制台打印播放流程 |
| 主页地址换成 `/三、开屏动画/?t=3.5` | 动画单独定格在 3.5 秒，逐帧核对画面 |

## 五、怎么发布到你的 GitHub Pages

改动的就三样东西：**新文件夹 `三、开屏动画/`**、**`index.html`**、**`_headers`**。

### 方式 A：网页上传（最简单，推荐）

1. 打开 https://github.com/Monarchish/Monarchish.github.io
2. 右上 **Add file → Upload files**
3. 把安装包里的 **`三、开屏动画` 文件夹整体拖进去**（别拖散文件），等进度条走完
4. 再点 **Add file → Upload files**，把新的 **`index.html`** 和 **`_headers`** 拖进去
   （同名文件会自动覆盖旧版，提交说明随便写，比如"添加开屏动画"）
5. 点 **Commit changes**
6. 等 1~2 分钟，打开 https://monarchish.github.io —— 应该先看到动画，播完进入主页
7. 想再播一次验证：开一个**新的标签页/无痕窗口**访问（同一会话内只播一次）

### 方式 B：git 命令

```bash
git clone https://github.com/Monarchish/Monarchish.github.io.git
cd Monarchish.github.io
# 把安装包里的 三、开屏动画 文件夹、index.html、_headers 覆盖进来，然后：
git add .
git commit -m "添加开屏动画"
git push
```

## 六、常见问题

- **每次进站都想播动画** → `overlay.js` 里 `oncePerSession: false`
- **觉得 5 秒太长/太短** → `intro-config.js` 里 `redirectAtSeconds`
- **不想让访客跳过** → `allowSkip: false`
- **想换掉标题/画面** → 素材在 `assets/images/`，同名替换即可（改完记得给文件名换版本号或清缓存）
- **手机上体验** → 动画会按 16:9 居中缩放，竖屏时自动旋转成 9:16 全屏；流量敏感是因为首次要下载约 4.5MB 素材（浏览器会缓存一年，二次访问秒开）
- **动画没播直接进了主页** → 可能是本会话已播过，用 `?intro=1` 强制；或 20 秒兜底判定加载失败放行了，看控制台日志排查
