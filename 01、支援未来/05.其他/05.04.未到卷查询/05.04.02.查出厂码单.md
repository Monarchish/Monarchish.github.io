# 查出厂码单

Open "台账"

Ctrl + C "台账" - "钢厂资源号（AF）"

Open "宝时达" - "全部菜单" - "货物管理" - "出厂码单"

Left Click "出厂码单" - "查询请点我"

Left Click "出厂码单" - "重置"

Ctrl + V "出厂码单" - "钢厂订单号"

Left Click "出厂码单" - "查询"

Ctrl + C "出厂码单" - "码单详情"

Open "和仓库的对话框"

Ctrl + V

Write "和仓库的对话框"

（码单已经有了，麻烦再找一下）

Enter

（如果仓库找到并回复在库，告知客户。）

（如果仓库仍然回复不在库，继续下一步。）
