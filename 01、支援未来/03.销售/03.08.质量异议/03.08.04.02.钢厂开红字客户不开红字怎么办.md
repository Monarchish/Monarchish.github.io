# 钢厂开红字客户不开红字怎么办

让财务开"红字信息表"，发给钢厂。

收到钢厂开具的"红字负数发票"。

将"质量异议 折扣申请表"，给财务。

Open "台账"

Ctrl + C "台账" - "捆包号"

Open "C9" - "财务管理" - "费用管理" - "经营费用登记"

Left Click "经营费用登记" - "单据编号" - "⋯"

Ctrl + V "经营费用登记" - "捆包号"

Write "经营费用登记" - "销售单"

（√）

Left Click "经营费用登记" - "查询"

Left Click "经营费用登记" - "全选"

Left Click "经营费用登记" - "确定"

Write "经营费用登记" - "费用名称"

（质量*异议）

Write "经营费用登记" - "往来类别"

（应收）

Write "经营费用登记" - "结算单位"

（【结算单位】）

Write "经营费用登记" - "金额"

（【负数金额】）

Write "经营费用登记" - "费用类别"

（财务费用）

Write "经营费用登记" - "结账方式"

（现结）

Left Click "经营费用登记" - "保存"

Left Click "经营费用登记" - "确定"

Left Click "经营费用登记" - "确定"
