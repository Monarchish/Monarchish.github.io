# 台账编辑

**文件编号**：03.02.03　　**所属环节**：销售 · 插行　　**版本**：v1.0

## 1. 作业目的

将「整理表格」筛出的捆包数据逐条插入销售台账，并完成关联字段填充与校验。

## 2. 适用范围

销售环节插行作业，在「整理表格」完成后执行。执行前须同时满足：

| 序号 | 前提条件 | 不满足时的处理 |
|:--:|---|---|
| 1 | 已完成「整理表格」，得到 sheet2（捆包号 / 净重 / 钢厂订单号三列） | 先执行「整理表格」 |
| 2 | 台账已打开且已完成隐藏列设置 | 见「整理表格」步骤 1 |

> **术语约定**：本文件所称「台账」指销售台账主表；「资源号」指台账中的「钢厂资源号」（AF 列）；「校验列」指台账中的串行校验列（BV 列）。

## 3. 作业步骤

<details class="sop-step">
<summary>步骤 1｜按资源号定位并插入行</summary>

```
Open "下载文件" - "sheet2"
Filter "钢厂订单号（C）" （单个资源号）
Ctrl + C "钢厂订单号（C）"
Open "台账"
Ctrl + F "台账" - "钢厂资源号（AF）"
Ctrl + V "台账" - "钢厂资源号（AF）"
Enter
Esc
Right Click "钢厂资源号（AF）" （在下方插入行）
```

| 级别 | 内容 |
|:--:|---|
| ⚠ 注意 | **一次只处理一个资源号**。sheet2 需按单个资源号筛选，逐个插入，不可批量。 |
| ⚠ 注意 | 若「捆包号（S）」为空，插入行数 = 捆包号数量 − 1。 |
| ⚠ 注意 | 若捆包号数量为 1，右键后直接按 B（粘贴），无需插入行。 |
| ⚠ 注意 | 插入位置在定位到的资源号**下方**，不可插入到上方。 |

**完成判定**：台账中目标资源号下方已插入与待插捆包数匹配的空行。

</details>

<details class="sop-step">
<summary>步骤 2｜粘贴捆包号与净重</summary>

```
Open "下载文件" - "sheet2"
Ctrl + C "捆包号（A）"
Ctrl + C "净重（B）"
Open "台账"
Ctrl + V "台账" - "捆包号（S）"
```

| 级别 | 内容 |
|:--:|---|
| ✓ 检验 | 粘贴后核对新插入行的捆包号、净重与 sheet2 完全一致，且未覆盖已有数据行。 |

**完成判定**：新插入行的「捆包号（S）」「净重」两列已正确填入。

</details>

<details class="sop-step">
<summary>步骤 3｜批量填充关联字段</summary>

```
Ctrl + D "台账" - "期别（Z）"
Ctrl + D "台账" - "品名（AA）"
…（Z 至 BW 逐列 Ctrl + D）
```

| 级别 | 内容 |
|:--:|---|
| ⚠ 注意 | 填充范围自「期别（Z）」起至「（BW）」止，**须逐列执行**，不可跳列。 |
| ⚠ 注意 | Ctrl + D 为向下填充，需先选中含参考数据的上一行，否则填充内容错误。 |

**完成判定**：Z–BW 全部列已填充，无空白单元格。

</details>

<details class="sop-step">
<summary>步骤 4｜校验串行结果</summary>

| 级别 | 内容 |
|:--:|---|
| ✓ 检验 | 「串行校验列（BV）」返回 **TRUE** 表示本次插行正确。 |
| ⛔ 禁止 | 「串行校验列（BV）」返回 **FALSE** 时不得继续。须检查原因并修正后重做。 |

**完成判定**：所有新插入行的 BV 列均为 TRUE。

> 重复步骤 1–4，直至 sheet2 中所有资源号处理完毕。

</details>

<details class="sop-step">
<summary>步骤 5｜回填毛重并保存</summary>

```
Open "下载文件" - "sheet1"
Ctrl + C "捆包号（A）"
Ctrl + C "准发毛重（D）"
Open "台账"
Ctrl + V "台账" - "（BX）"
Filter "台账" - "（BW）" （非#N/A）
Ctrl + C "台账" - "（BW）"
Right Click "台账" - "毛重（R）" （粘贴值到可见单元格）
Ctrl + S "台账"
```

| 级别 | 内容 |
|:--:|---|
| ⚠ 注意 | 须使用「**粘贴值到可见单元格**」，不可直接粘贴。否则筛选状态下的隐藏行会被一并覆盖。 |
| ✓ 检验 | 粘贴后核对台账「毛重（R）」列，确认已填入准发毛重且未影响其他行。 |

**完成判定**：毛重列回填完成，台账已保存。

</details>

## 4. 常见异常处理

| 异常现象 | 处理方式 |
|---|---|
| 校验列 BV 返回 FALSE | 逐项核对：插入行数是否正确、捆包号是否错位、Ctrl + D 填充范围是否完整；修正后重做该资源号。 |
| 插入行后数据错位 | 撤销（Ctrl + Z）后重新执行步骤 1，注意插入位置在资源号下方。 |
| 毛重粘贴后其他行数据异常 | 检查是否误用普通粘贴；撤销后改用「粘贴值到可见单元格」。 |
