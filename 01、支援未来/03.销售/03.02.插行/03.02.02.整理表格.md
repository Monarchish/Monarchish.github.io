# 整理表格

**文件编号**：03.02.02　　**所属环节**：销售 · 插行　　**版本**：v1.0

## 1. 作业目的

从下载的准发数据中筛出属于本业务范围、且尚未录入台账的捆包号，作为「台账编辑」的输入。

## 2. 适用范围

销售环节插行作业，在「准发下载」完成后执行。执行前须同时满足：

| 序号 | 前提条件 | 不满足时的处理 |
|:--:|---|---|
| 1 | 已完成「准发下载」，得到多列合并的下载文件 | 先执行「准发下载」 |
| 2 | 台账文件已打开 | 先打开台账 |
| 3 | 台账已隐藏不需要的列 | 先执行步骤 1 |

> **术语约定**：本文件所称「台账」指销售台账主表；「下载文件」指由宝时达导出的 Excel 文件；「资源号」指台账中的「钢厂资源号」（AF 列）。

## 3. 作业步骤

<details class="sop-step">
<summary>步骤 1｜隐藏台账中不需要的列</summary>

```
Open "台账"
Right Click "台账" - "销售单价（AH）" （隐藏）
Right Click "台账" - "销售金额（AI）" （隐藏）
…（AH 至 BU 逐列隐藏）
Ctrl + S "台账"
```

| 级别 | 内容 |
|:--:|---|
| ⚠ 注意 | 隐藏操作**只影响显示，不改动台账内容**。目的是让插行所需的列集中可见，避免插行时点错列。 |
| ⚠ 注意 | 隐藏范围自「销售单价（AH）」起至「凡川出入库统计（BU）」止。 |

**完成判定**：台账 AH–BU 列已隐藏，插行所需列（A–AG）在屏幕上连续可见。

</details>

<details class="sop-step">
<summary>步骤 2｜用 VLOOKUP 取出钢厂资源号</summary>

```
Open "台账"
Ctrl + C "台账" - "钢厂资源号（AF）"
Open "下载文件" - "Sheet1"
Ctrl + V （F 列）
Write "（E）" （=VLOOKUP（钢厂订单号（C），F：G，2，0））
Ctrl + D "（E）"
```

| 级别 | 内容 |
|:--:|---|
| ⚠ 注意 | VLOOKUP 的查找值取「钢厂订单号（C）」，返回台账中的「钢厂资源号」，用于判断该捆包归属哪个业务。 |
| ✓ 检验 | 填充后抽查若干行，确认资源号正常返回；出现 `#N/A` 说明台账中无对应资源号。 |

**完成判定**：下载文件 F 列已填入全部资源号，E 列公式填充至数据末行。

</details>

<details class="sop-step">
<summary>步骤 3｜筛选出本业务需要的行</summary>

```
Open "台账"
Ctrl + C "台账" - "捆包号（S）"
Open "下载文件" - "Sheet1"
Ctrl + V "捆包号（A）"
Alt + 2 "捆包号（A）"
Filter "（E）" （0）
Filter "捆包号（A）" （颜色为无填充）
```

| 级别 | 内容 |
|:--:|---|
| ⚠ 注意 | **两道筛选缺一不可**：① 「（E）」筛除 0 值，排除非本业务的资源号；② 「捆包号（A）」筛颜色为无填充，排除已在台账中的捆包号。 |
| ⚠ 注意 | 存量台账中的捆包号带有填充色。**颜色为无填充即表示尚未录入**，是本次需要处理的数据。 |
| ✓ 检验 | 筛选后剩余的行数应与实际待插行数量吻合。 |

**完成判定**：表格中仅保留「本业务资源号 + 尚未录入台账」的行。

</details>

<details class="sop-step">
<summary>步骤 4｜导出待插行数据</summary>

```
Ctrl + C "捆包号（A）"
Ctrl + C "净重（B）"
Ctrl + C "钢厂订单号（C）"
Open "下载文件" - "sheet2"
Ctrl + V
Right Click "捆包号（A）" （20）
Right Click "钢厂订单号（C）" （20）
```

| 级别 | 内容 |
|:--:|---|
| ⚠ 注意 | 此处**仅复制筛选后的可见行**，不保留原表的筛选状态。原表带筛选条件不利于后续插行操作，故另存到 sheet2。 |
| ✓ 检验 | sheet2 中三列齐全、无空行，行数与步骤 3 的筛选结果一致。 |

**完成判定**：sheet2 生成仅含捆包号、净重、钢厂订单号三列的干净数据。

</details>

## 4. 常见异常处理

| 异常现象 | 处理方式 |
|---|---|
| VLOOKUP 结果整列为 `#N/A` | 检查台账是否已打开、公式引用的区域是否正确（F:G）。 |
| 筛选后无剩余行 | 说明该批捆包均已录入台账，无插行任务。 |
| 筛选后行数明显偏多 | 检查颜色筛选条件是否遗漏，或捆包号是否被误改格式。 |
