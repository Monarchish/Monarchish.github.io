# 宝钢发票

Open "宝时达" - "全部菜单" - "资金管理" - "销售发票查询"

Left Click "销售发票查询" - "查询请点我"

Left Click "销售发票查询" - "重置"

Write "销售发票查询" - "开票时间起"

（【开票时间起】）

Write "销售发票查询" - "开票时间止"

（【开票时间止】）

Left Click "销售发票查询" - "查询"

Left Click "销售发票查询" - "个性化捆包下载"

Open "下载文件"

Ctrl + C "捆包号（G）"

Ctrl + C "不含税单价（O）"

Open "台账"

Ctrl + V "台账" - "（BX）"

Filter "台账" - "（BW）"

（非#N/A）

Ctrl + C "台账" - "（BW）"

Right Click "台账" - "单价（不含税）（I）"

（粘贴值到可见单元格）

Write "台账" - "不含税金额"

（=单价（不含税）（I）*吨位（T））

Write "台账" - "税额"

（=不含税金额（J）*0.13）

Write "台账" - "单价（含税）"

（=单价（不含税）（I）*1.13）

Write "台账" - "发票总额（含税）"

（=单价（含税）（L）*吨位（T））

Write "台账" - "发票与合同单价差异（检查＞0部分）"

（=单价（含税）（L）-采购单价含税（BB））

Ctrl + D "台账" - "不含税金额"

Ctrl + D "台账" - "税额"

Ctrl + D "台账" - "单价（含税）"

Ctrl + D "台账" - "发票总额（含税）"

Ctrl + D "台账" - "发票与合同单价差异（检查＞0部分）"

（如果是0则没问题）
