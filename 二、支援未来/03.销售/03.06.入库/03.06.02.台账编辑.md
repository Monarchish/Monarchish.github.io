# 台账编辑

Open "云仓库存"

Write "捆包号（C）"

（转换为数字）

Ctrl + C "捆包号（C）"

Open "台账"

Ctrl + V "台账" - "（BX）"

Open "云仓库存"

Ctrl + C "仓库名称（B）"

Open "台账"

Ctrl + V "台账" - "（BY）"

Filter "台账" - "（BW）"

（非#N/A）

Filter "台账" - "入库日期（V）"

（空白）

Ctrl + ; "台账" - "入库日期（V）"

Ctrl + D "台账" - "入库日期（V）"

（按"（BW）"列的数据，核对是否与"客户（AG）"相同。不同的台账则需要修改。）

Ctrl + S "台账"
