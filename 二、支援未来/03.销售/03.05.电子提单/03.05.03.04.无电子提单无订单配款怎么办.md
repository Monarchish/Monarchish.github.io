# 无电子提单无订单配款怎么办

Open "提货委托书"

Ctrl + C "捆包号（D）"

Open "欧冶云仓" - "物流管理" - "我的入库" - "入库跟踪" - "仓库入库实绩"

Ctrl + V "捆包号"

Left Click "查询"

（如果没有，则问仓库这个卷在不在我们名下。）

（如果还是没有，则让仓库截图不在我们名下的截图。）

Ctrl + Alt + A "图片内容"

（货主名称，捆包号，净重，毛重，张/件/支数，库位号）

Open "IEC用户问题沟通群"

Ctrl + V "对话框"

Open "宝时达" - "全部菜单" - "货物管理" - "电子提单" - "提货单委托"

Ctrl + Alt + A "提货单委托"

（提货单号，销售订单号，钢厂订单号，提单重量（吨），是否过户，提单委托及验收状态，仓库，是否厂商银提单，开单日期）

Open "IEC用户问题沟通群"

Ctrl + V "对话框"

Write "对话框"

（@IEC-蔡译锋 捆包号：【x】，提单号：【x】，提单早就开了，货权还在钢贸，老师麻烦帮忙处理下。）
