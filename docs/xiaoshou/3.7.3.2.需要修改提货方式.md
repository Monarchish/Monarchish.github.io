# 需要修改提货方式

Open "台账"

Ctrl + C "台账" - "捆包号"

Open "C9" - "销售管理" - "现货销售管理" - "销售开单"

Left Click "销售开单" - "查询"

Left Click "销售开单" - "清空条件"

Left Click "销售开单" - "捆包号"

Ctrl + V

Left Click "销售开单" - "查询"

Double Click "销售开单" - "捆包号"

Write "销售开单" - "提货凭证类"

（转货权 Or 车牌号）

Write "销售开单" - "转入单位"

（转货权时填写。如有特殊备注，则Write "备注"）

Write "销售开单" - "车号"

（车牌号时填写。如有车号填不下，则Write "备注"）

Left Click "销售开单" - "保存"
