# 客户档案表

维护和更新客户及供应商的基础档案信息。

## 操作流程

### 基本信息填写

1. **Open** `客户档案表`
2. **Write** `客户档案表 → 客户基本信息 → 客户名称`
   - 输入值：`【客户名称】`
3. **Write** `客户档案表 → 客户基本信息 → 注册/办公地址`
   - 输入值：`【注册/办公地址】`
4. **Write** `客户档案表 → 客户基本信息 → 实际控制人`
   - 输入值：`【实际控制人】`
5. **Write** `客户档案表 → 客户基本信息 → 法人代表`
   - 输入值：`【法人代表】`
6. **Write** `客户档案表 → 客户基本信息 → 成立时间`
   - 输入值：`【成立时间】`
7. **Write** `客户档案表 → 客户基本信息 → 所属行业`
   - 输入值：`【所属行业】`
8. **Write** `客户档案表 → 客户基本信息 → 企业性质`
   - 输入值：央企 或 国企 或 外企 或 合资 或 民企 或 个体
9. **Write** `客户档案表 → 客户基本信息 → 注册资本`
   - 输入值：`【注册资本】`

### 客户特征信息填写

1. **Write** `客户档案表 → 客户特征信息 → 营业规模`
   - 输入值：大型 或 中型 或 小型 或 微型
2. **Write** `客户档案表 → 客户特征信息 → 发展阶段`
   - 输入值：上升期 或 稳定期 或 萎缩期 或 艰难生存
3. **Write** `客户档案表 → 客户特征信息 → 人员规模`
   - 输入值：`【人员规模】`
4. **Write** `客户档案表 → 客户特征信息 → 行业地位`
   - 输入值：领先者 或 中上游 或 中游 或 中下游
5. **Write** `客户档案表 → 客户特征信息 → 采购物资品类及数量`
   - 输入值：冷轧板卷 或 酸洗板卷 或 电镀锌板卷
6. **Write** `客户档案表 → 客户特征信息 → 主要供应商`
   - 输入值：`【主要供应商】`

### 采购联系人信息

1. **Write** `客户档案表 → 客户特征信息 → 采购联系人 → 姓名`
   - 输入值：`【采购联系人 - 姓名】`
2. **Write** `客户档案表 → 客户特征信息 → 采购联系人 → 职务`
   - 输入值：`【采购联系人 - 职务】`
3. **Write** `客户档案表 → 客户特征信息 → 采购联系人 → 联系方式`
   - 输入值：`【采购联系人 - 联系方式】`
4. **Write** `客户档案表 → 客户特征信息 → 采购联系人 → 个人信息`
   - 输入值：`【采购联系人 - 个人信息】`

### 采购负责人信息

1. **Write** `客户档案表 → 客户特征信息 → 采购负责人 → 姓名`
   - 输入值：`【采购负责人 - 姓名】`
2. **Write** `客户档案表 → 客户特征信息 → 采购负责人 → 职务`
   - 输入值：`【采购负责人 - 职务】`
3. **Write** `客户档案表 → 客户特征信息 → 采购负责人 → 联系方式`
   - 输入值：`【采购负责人 - 联系方式】`
4. **Write** `客户档案表 → 客户特征信息 → 采购负责人 → 个人信息`
   - 输入值：`【采购负责人 - 个人信息】`

### 客户合作资料填写

1. **Write** `客户档案表 → 客户合作资料 → 合作品种`
   - 输入值：冷轧板卷 或 酸洗板卷 或 电镀锌板卷
2. **Write** `客户档案表 → 客户合作资料 → 累计交易额`
   - 输入值：`-`
3. **Write** `客户档案表 → 客户合作资料 → 上年度交易额`
   - 输入值：`-`
4. **Write** `客户档案表 → 客户合作资料 → 采购方式`
   - 输入值：年度协议 或 一单一议
5. **Write** `客户档案表 → 客户合作资料 → 付款方式`
   - 输入值：全款订货 或 见票付款
6. **Write** `客户档案表 → 客户合作资料 → 业务模式`
   - 输入值：背靠背 或 非背靠背
7. **Write** `客户档案表 → 客户合作资料 → 我方供应占比`
   - 输入值：`-`
8. **Write** `客户档案表 → 客户合作资料 → 在我方销售额占比`
   - 输入值：`-`
9. **Write** `客户档案表 → 客户合作资料 → 在我方利润占比`
   - 输入值：`-`

### 赊销客户信息（如适用）

1. **Write** `客户档案表 → 客户合作资料 → 针对赊销客户 → 客户评级`
   - 输入值：`-`
2. **Write** `客户档案表 → 客户合作资料 → 针对赊销客户 → 授信额度`
   - 输入值：`-`
3. **Write** `客户档案表 → 客户合作资料 → 针对赊销客户 → 评级时间`
   - 输入值：`-`

### 保存

1. **Ctrl + S** `客户档案表`
