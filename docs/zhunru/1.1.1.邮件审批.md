# 邮件审批

## 操作流程

**`Open`** “W365 - 邮箱 - 写邮件”

**`Write`** “新邮件 - 收件人”  
（【收件人】）

**`Write`** “新邮件 - 抄送”  
（【抄送】）

**`Write`** “新邮件 - 主题”  
（新增客户申请：【客户名称】 Or 新增供应商申请：【供应商名称】）

**`Write`** “新邮件 - 内容”  
（<br>
  新客户 【客户名称】 现有 【产地】 【品名】 的期货需求，<br>
  其订货量约 【x】 吨/月，供应商 【钢厂名称】。<br>
  付款方式：【付款方式】。交货地：【交货地】。<br>
  现申请新客户准入申请流程，请您批示，谢谢！<br>
）

**`Left Click`** “新邮件 - 发送”

## 审批截图存档

**`Open`** “W365 - 邮箱 - 收件箱”  

**`Ctrl + Alt + A`** “准入邮件”  

**`Ctrl + S`** “保存截图至桌面”  

**`Write`** “图片”  
（邮件审批）
