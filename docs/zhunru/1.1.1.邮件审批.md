# 邮件审批

发送新增客户或供应商的准入审批邮件。

## 操作流程

1. **Open** `W365 - 邮箱 - 写邮件`
2. **Write** `新邮件 → 收件人`
   - 输入值：`【收件人】`
3. **Write** `新邮件 → 抄送`
   - 输入值：`【抄送】`
4. **Write** `新邮件 → 主题`
   - 输入值：新增客户申请：`【客户名称】` 或 新增供应商申请：`【供应商名称】`
5. **Write** `新邮件 → 内容`
   - 输入值：新客户 `【客户名称】` 现有 `【产地】` `【品名】` 的期货需求，其订货量约 `【x】` 吨/月，供应商 `【钢厂名称】`。付款方式：`【付款方式】`。交货地：`【交货地】`。现申请新客户准入申请流程，请您批示，谢谢！
6. **Left Click** `新邮件 → 发送`

## 审批截图存档

1. **Open** `W365 - 邮箱 → 收件箱`
2. **Ctrl + Alt + A** 搜索 `准入邮件`
3. **Ctrl + S** 保存截图至桌面
   - 图片命名：`邮件审批`
