# 同创浦江合同审批流程-变更

Open "集团网站" - "流程与公文" - "流程地图" - "所有流程" - "我的申请"

Left Click "同创浦江合同审批申请表"

Left Click "复制流程"

Write "采购合同名称"

（钢铁产品采购合同 - 变更）

Write "销售合同名称"

（【销售合同名称】 - 变更）

Write "采购单价"

（【销售单价】）

Write "销售单价"

（【销售单价】）

Write "采购总金额"

（【采购总金额】）

Write "销售总金额"

（【销售总金额】）

Write "合同有关概述"

（由于采购合同变更，销售合同金额由【X】元变更为【X】元。）

Write "附件"

（采购合同，销售合同）

Left Click "提交"
