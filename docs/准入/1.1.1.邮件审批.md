# 邮件审批

发送新增客户或供应商的准入审批邮件。

## 操作流程

1. **Open** `W365 - 邮箱 - 写邮件`
2. **Write** `新邮件 → 收件人`
   （`【收件人】`）
3. **Write** `新邮件 → 抄送`
   （`【抄送】`）
4. **Write** `新邮件 → 主题`
   （新增客户申请：`【客户名称】` 或 新增供应商申请：`【供应商名称】`）
5. **Write** `新邮件 → 内容`
   （
     新客户 `【客户名称】` 现有 `【产地】` `【品名】` 的期货需求，
     其订货量约 `【x】` 吨/月，供应商 `【钢厂名称】`。
     付款方式：`【付款方式】`。交货地：`【交货地】`。
     现申请新客户准入申请流程，请您批示，谢谢！
   ）
6. **Left Click** `新邮件 → 发送`

## 审批截图存档

1. **Open** `W365 - 邮箱 → 收件箱`
2. **Ctrl + Alt + A** 搜索 `准入邮件`
3. **Ctrl + S** 保存截图至桌面
   （图片命名：`邮件审批`）

## 占位符说明

| 占位符 | 说明 |
|--------|------|
| `【收件人】` | 审批人邮箱地址 |
| `【抄送】` | 相关知情人邮箱地址 |
| `【客户名称】` / `【供应商名称】` | 申请准入的公司全称 |
| `【产地】` | 货物产地 |
| `【品名】` | 货物名称 |
| `【x】` | 预估月订货量（吨） |
| `【钢厂名称】` | 对应钢厂 |
| `【付款方式】` | 如：现款、承兑等 |
| `【交货地】` | 交货地点 |

## 注意事项

- 发送前请确认收件人、抄送人正确
- 客户名称/供应商名称请使用工商注册全称
- 审批截图需保存至对应客户/供应商文件夹中
