# 组织架构

在 MDG 系统中为新增客户/供应商创建组织架构信息。

## 操作流程

1. **Open** `集团网站 → 专题门户 → SAP应用 → MDG → 业务伙伴治理 → /nwbc → 业务伙伴治理 → 搜索业务伙伴 → 新建 → 组织架构`

### 变更请求

2. **Write** `组织架构 → 变更请求 → 描述`
   - 输入值：新增客户 或 新增供应商

### 业务伙伴明细

3. **Write** `组织架构 → 业务伙伴明细 → 业务伙伴标识/分组`
   - 输入值：境内企业
4. **Write** `组织架构 → 业务伙伴明细 → 名称 1`
   - 输入值：`【名称 1】`
5. **Write** `组织架构 → 业务伙伴明细 → 国家`
   - 输入值：CN
6. **Write** `组织架构 → 业务伙伴明细 → 语言`
   - 输入值：ZH
7. **Write** `组织架构 → 业务伙伴明细 → 地区`
   - 输入值：`【地区】`
8. **Write** `组织架构 → 业务伙伴明细 → 城市`
   - 输入值：`【城市】`
9. **Write** `组织架构 → 业务伙伴明细 → 行政区`
   - 输入值：`【行政区】`
10. **Write** `组织架构 → 业务伙伴明细 → 街道/门牌号`
    - 输入值：`【街道/门牌号】`

### 角色

11. **Write** `组织架构 → 角色 → 新建 → 业务伙伴角色`
    - 输入值：FI 集团客户、集团客户 或 FI 集团供应商、集团供应商

### 银行账户

12. **Write** `组织架构 → 银行账户 → 新建 → 银行账户`
    - 输入值：`【银行账户】`
13. **Write** `组织架构 → 银行账户 → 新建 → 银行所在国`
    - 输入值：CN
14. **Write** `组织架构 → 银行账户 → 新建 → 银行代码`
    - 输入值：`【银行代码】`

### 标识号

15. **Write** `组织架构 → 标识号 → 新建 → 标识类型`
    - 输入值：ZID001
16. **Write** `组织架构 → 标识号 → 新建 → 标识编号`
    - 输入值：`【统一社会信用代码】`

### 税号

17. **Write** `组织架构 → 税号 → 新建 → 税号类别`
    - 输入值：CN0
18. **Write** `组织架构 → 税号 → 新建 → 税号`
    - 输入值：`【统一社会信用代码】`

### 文件管理

19. **Write** `组织架构 → 文件管理 → 上传文件`
    - 输入值：营业执照

### 提交

20. **Left Click** `组织架构 → 提交`
