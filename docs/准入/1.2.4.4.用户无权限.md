# 出现“当前用户无权限，请联系管理员！”时，该怎么办？

## 操作流程

1. **Open** `集团网站 → 流程与公文 → 流程地图 → 集团公司 → SAP流程 → MDG用户权限申请流程`

### 制单人及单据信息

2. **Write** `MDG用户权限申请表 → 制单人`
   - 输入值：`【制单人】`
3. **Write** `MDG用户权限申请表 → 单据编号`
   - 输入值：`-`

### 申请信息

4. **Write** `MDG用户权限申请表 → 申请信息 → 申请人`
   - 输入值：`【申请人】`
5. **Write** `MDG用户权限申请表 → 申请信息 → 企业工号`
   - 输入值：`【企业工号】`
6. **Write** `MDG用户权限申请表 → 申请信息 → 所属部门`
   - 输入值：`【所属部门】`
7. **Write** `MDG用户权限申请表 → 申请信息 → 所属岗位`
   - 输入值：`【所属岗位】`
8. **Write** `MDG用户权限申请表 → 申请信息 → 所属公司`
   - 输入值：中集同创浦江(上海)贸易有限公司
9. **Write** `MDG用户权限申请表 → 申请信息 → 申请日期`
   - 输入值：`【申请日期】`
10. **Write** `MDG用户权限申请表 → 申请信息 → 邮箱`
    - 输入值：`【邮箱】`
11. **Write** `MDG用户权限申请表 → 申请信息 → SAP账号`
    - 输入值：`【SAP账号】`
12. **Write** `MDG用户权限申请表 → 申请信息 → 所属板块`
    - 输入值：`【所属板块】`
13. **Write** `MDG用户权限申请表 → 申请信息 → 申请原因`
    - 输入值：业务需要开通MDG
14. **Write** `MDG用户权限申请表 → 申请信息 → 操作类型`
    - 输入值：新增
15. **Write** `MDG用户权限申请表 → 申请信息 → 用户类型`
    - 输入值：申请者

### 申请明细

16. **Left Click** `MDG用户权限申请表 → 申请明细 → 业务伙伴`
17. **Left Click** `MDG用户权限申请表 → 申请明细 → 角色 → 主数据通用角色`
18. **Left Click** `MDG用户权限申请表 → 申请明细 → 权限 → 主数据通用角色`
19. **Write** `MDG用户权限申请表 → 申请明细 → 部门领导审批人`
    - 输入值：`【部门领导审批人】`

### 附件信息 — MDG培训表及考试试卷

20. **Left Click** `MDG用户权限申请表 → 附件信息 → MDG培训表及考试试卷 → MDG培训签到表 → 下载`
21. **Open** `MDG培训签到表`
22. **Write** `MDG培训签到表 → 培训内容`
    - 输入值：MDG基本操作流程
23. **Write** `MDG培训签到表 → 培训时间`
    - 输入值：`【培训时间】`
24. **Write** `MDG培训签到表 → 培训地点`
    - 输入值：`【培训地点】`
25. **Write** `MDG培训签到表 → 培训讲师`
    - 输入值：`【培训讲师】`
26. **Write** `MDG培训签到表 → 序号`
    - 输入值：`【序号】`
27. **Write** `MDG培训签到表 → 参加人`
    - 输入值：`【参加人】`
28. **Write** `MDG培训签到表 → 公司`
    - 输入值：中集同创浦江（上海）贸易有限公司
29. **Write** `MDG培训签到表 → 部门`
    - 输入值：`【部门】`
30. **Write** `MDG培训签到表 → 签到`
    - 输入值：√
31. **Ctrl + S** `MDG培训签到表`

### 附件信息 — MDG系统操作通用考试卷

32. **Left Click** `MDG用户权限申请表 → 附件信息 → MDG培训表及考试试卷 → MDG系统操作通用考试卷 → 下载`
33. **Open** `MDG系统操作通用考试卷`
34. **Write** `MDG系统操作通用考试卷 → 公司`
    - 输入值：中集同创浦江（上海）贸易有限公司
35. **Write** `MDG系统操作通用考试卷 → 部门`
    - 输入值：`【部门】`
36. **Write** `MDG系统操作通用考试卷 → 姓名`
    - 输入值：`【姓名】`
37. **Write** `MDG系统操作通用考试卷 → 工号`
    - 输入值：`【工号】`
38. **Write** `MDG系统操作通用考试卷 → 试卷`
    - 输入值：`【答案】`
39. **Ctrl + S** `MDG系统操作通用考试卷`

### 附件信息 — MDG账号及审批权限收集表（批量申请）

40. **Left Click** `MDG用户权限申请表 → 附件信息 → MDG账号及审批权限收集表（批量申请） → MDG用户角色及审批权限收集表模板 → 下载`
41. **Open** `MDG用户角色及审批权限收集表模板`
42. **Write** `MDG用户角色及审批权限收集表模板 → 用户`
    - 输入值：`【工号】`
43. **Write** `MDG用户角色及审批权限收集表模板 → 姓名`
    - 输入值：`【姓名】`
44. **Write** `MDG用户角色及审批权限收集表模板 → 电话`
    - 输入值：`【电话】`
45. **Write** `MDG用户角色及审批权限收集表模板 → 邮箱`
    - 输入值：`【邮箱】`
46. **Write** `MDG用户角色及审批权限收集表模板 → 公司`
    - 输入值：中集同创浦江（上海）贸易有限公司
47. **Write** `MDG用户角色及审批权限收集表模板 → 公司代码`
    - 输入值：1675
48. **Write** `MDG用户角色及审批权限收集表模板 → 部门`
    - 输入值：`【部门】`
49. **Write** `MDG用户角色及审批权限收集表模板 → 职称`
    - 输入值：`【职称】`
50. **Write** `MDG用户角色及审批权限收集表模板 → 有效期自`
    - 输入值：`【有效期自】`
51. **Write** `MDG用户角色及审批权限收集表模板 → 有效期至`
    - 输入值：`【有效期至】`
52. **Ctrl + S** `MDG用户角色及审批权限收集表模板`

### 附件汇总及提交

53. **Open** `MDG用户权限申请表 → 附件信息`
54. **Write** `MDG用户权限申请表 → 附件信息 → MDG培训表及考试试卷`
    - 输入值：MDG培训签到表、MDG系统操作通用考试卷
55. **Write** `MDG用户权限申请表 → 附件信息 → MDG账号及审批权限收集表（批量申请）`
    - 输入值：MDG用户角色及审批权限收集表模板
56. **Left Click** `MDG用户权限申请表 → 提交`
