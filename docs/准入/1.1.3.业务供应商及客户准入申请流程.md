# 业务供应商及客户准入申请流程

供应商及客户准入的完整审批流程。

## 操作流程

1. **Open** `集团网站 → 流程与公文 → 流程地图 → 同创板块 → SAP流程 → 业务供应商及客户准入申请流程`

### 制单人及单据信息

2. **Write** `业务供应商及客户准入申请表 → 制单人`
   - 输入值：`【制单人】`
3. **Write** `业务供应商及客户准入申请表 → 单据编号`
   - 输入值：`-`

### 申请信息

4. **Write** `业务供应商及客户准入申请表 → 申请信息 → 申请人`
   - 输入值：`【申请人】`
5. **Write** `业务供应商及客户准入申请表 → 申请信息 → 企业工号`
   - 输入值：`【企业工号】`
6. **Write** `业务供应商及客户准入申请表 → 申请信息 → 所属部门`
   - 输入值：`【所属部门】`
7. **Write** `业务供应商及客户准入申请表 → 申请信息 → 所属岗位`
   - 输入值：`【所属岗位】`
8. **Write** `业务供应商及客户准入申请表 → 申请信息 → 所属公司`
   - 输入值：中集同创_中集同创浦江(上海)贸易有限公司
9. **Write** `业务供应商及客户准入申请表 → 申请信息 → 申请日期`
   - 输入值：`【申请日期】`

### 基本信息

10. **Write** `业务供应商及客户准入申请表 → 基本信息 → 合作单位`
    - 输入值：`【客户名称】`
11. **Write** `业务供应商及客户准入申请表 → 基本信息 → 合作单位类型`
    - 输入值：供应商 或 销售客户
12. **Write** `业务供应商及客户准入申请表 → 基本信息 → 成立日期`
    - 输入值：`【成立日期】`
13. **Write** `业务供应商及客户准入申请表 → 基本信息 → 单位类型`
    - 输入值：`【单位类型】`
14. **Write** `业务供应商及客户准入申请表 → 基本信息 → 注册资本`
    - 输入值：`【注册资本】`
15. **Write** `业务供应商及客户准入申请表 → 基本信息 → 法定代表人`
    - 输入值：`【法定代表人】`
16. **Write** `业务供应商及客户准入申请表 → 基本信息 → 公司规模`
    - 输入值：大型 或 中型 或 小型 或 微型
17. **Write** `业务供应商及客户准入申请表 → 基本信息 → 资信及背景概述`
    - 输入值：经营情况良好，无不良资信记录
18. **Write** `业务供应商及客户准入申请表 → 基本信息 → 是否为实地考察`
    - 输入值：是 或 否
19. **Write** `业务供应商及客户准入申请表 → 基本信息 → 办公场所`
    - 输入值：自有 或 租赁
20. **Write** `业务供应商及客户准入申请表 → 基本信息 → 场所面积(平米)`
    - 输入值：`【场所面积(平米)】`
21. **Write** `业务供应商及客户准入申请表 → 基本信息 → 人员规模(人数)`
    - 输入值：`【人员规模(人数)】`
22. **Write** `业务供应商及客户准入申请表 → 基本信息 → 工商登记信息`
    - 输入值：正常 或 非正常
23. **Write** `业务供应商及客户准入申请表 → 基本信息 → 诉讼记录`
    - 输入值：有 或 无
24. **Write** `业务供应商及客户准入申请表 → 基本信息 → 其他处罚记录`
    - 输入值：有 或 无
25. **Write** `业务供应商及客户准入申请表 → 基本信息 → 实缴资本`
    - 输入值：`【实缴资本】`
26. **Write** `业务供应商及客户准入申请表 → 基本信息 → 交易模式`
    - 输入值：与现有模式一致（15%定金，带款提货）
27. **Write** `业务供应商及客户准入申请表 → 基本信息 → 申请人申请说明`
    - 输入值：`【客户名称】` 成立于 `【X】` 年，主要经营 `【X】` 等。该公司经营情况良好，无不良资信记录。

### 审核信息

28. **Write** `业务供应商及客户准入申请表 → 审核信息 → 直属领导`
    - 输入值：`【直属领导】`
29. **Write** `业务供应商及客户准入申请表 → 审核信息 → 分管领导`
    - 输入值：`【分管领导】`
30. **Write** `业务供应商及客户准入申请表 → 审核信息 → 业务中心领导审批`
    - 输入值：`-`
31. **Write** `业务供应商及客户准入申请表 → 审核信息 → 附件`
    - 输入值：邮件审批、客户档案表、开票资料、营业执照

### 提交

32. **Left Click** `业务供应商及客户准入申请表 → 提交`
